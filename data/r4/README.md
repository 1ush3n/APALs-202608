# r4：五技能正式重调度资产

`r4` 是五技能 APAL 重调度的正式数据资产，唯一可运行协议为
`explicit_fiveskill_v1`。它以 `data/680.csv` 的显式
`专业编码` 与 `工种` 字段生成 30 个 400–600 物理工序训练图；每张训练图都必须
覆盖工种 0–4，并经过 DAG、专业—工种映射、工人覆盖和训练基准硬约束审计。

目录约定：

- `t/`：30 个训练图和其生成 manifest；
- `b/t/`：训练图的初始合法基准排程；
- `b/r/`：四真实实例的已核验基准排程副本；
- `s/`：四真实实例固定 low/medium/high（各 20）场景及 metadata 副本；
- `m.json`：唯一可用于 r4 训练/验证的 manifest，包含数据、基准和场景 SHA-256；
- `integrity_check.json`：哈希、语义、场景和 reset 审计结果。

训练入口会将 `m.json` 的 30 个训练 CSV 与 `train_data_path_or_dir` 目录逐一精确比对；
目录中任何额外、缺失或哈希变化的 CSV 都会拒绝启动。

`r3` 训练图缺少显式技能字段并在历史加载器中塌缩为工种 0；其训练及派生结果仅作历史
调试证据，**不可训练、不可正式评估、不可混合统计**。r4 复用 r3 中已通过核验的四真实
实例基准与固定场景，以保持测试场景可比；训练图和训练基准全部重新生成。
