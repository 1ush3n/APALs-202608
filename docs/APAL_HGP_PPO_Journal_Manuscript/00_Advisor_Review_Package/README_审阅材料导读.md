## 二、 本次版本重点加固的核心创新与理论要点

1. **三维联合决策与动作空间爆炸消除**：
   - 针对“工序先后序、站位平衡、多技能协作团队”强耦合导致的 $\binom{n_i}{q_i}$ 组合动作爆炸，提出**分层条件自回归指针解码器**，将庞大的离散联合动作分解为“工序 $\to$ 站位 $\to$ 逐个协同工人”的三级序贯选取过程；
   - 配合动态动作掩码与确定性前向时空推进引擎，确保生成的每一步决策 100% 满足工艺先后序、站位单调性、站位并发槽位容量与技能要求。
2. **工人“首次选择后内生绑定”机制**：
   - 打破传统装配调度中“先固定站位工人、再排工序”造成的资源能力与动态负载脱节弊端；所有工人初始全局自由，首次被指派到某站位工序时在决策中被内生锁定，自然适应各站位实际工作量。
3. **理论形式化与代码 100% 严密对齐**：
   - **有序轨迹 vs. 无序团队**：区分实际采样的有序动作序列 $\widetilde a_t=(i_t, m_t, \mathbf w_t)$（用于计算自回归联合似然与 PPO 优势更新）与环境物理执行的无序团队集合 $W_t$（用于团队变更率评估），消除了概率公式中的对象不一致问题；
   - **Worker Pointer 形式化打分**：形式化提炼了加性注意力打分函数 $u_{w,t}^{(r)} = \mathbf v_W^\top \tanh(\mathbf q_t^{(r)} + \mathbf k_{w,t}^{(r)})$ 与非法候选 $-10^4$ 掩码；
   - **置换不变的部分团队表示**：附录 A 形式化交代了对已选成员的三路对称池化 $[\mathrm{Sum} \,\|\, \mathrm{Mean} \,\|\, \mathrm{Max}]$，证明了团队状态对工人挑选顺序的数学不敏感性。
4. **工业级规模外推与在线秒级重调度实证**：
   - 锁定策略在 4 组真实工厂实例（283、680、2338、3182 道工序）上实现零样本泛化，相较 L2D-PPO 基线平均缩短周期跨度 2.22%，最大规模缩短 181.02 小时（10.03%）；
   - 在 36 组物料延迟扰动场景下，重调度模型实现 100% 物理可行率，综合目标 $S$ 显著优于传统启发式与经典修复规则；在 3182 道工序最大规模下，单场景在线修复仅需约 2 分钟（123.6 秒），相比传统元启发式搜索（65–72 分钟）具备工程实时的巨大优势。
