> 本大纲用于说明论文准备写什么、各章承担什么功能，以及正文每一段的大致内容。当前实验尚未全部完成，因此实验章以待验证问题和计划证据为主，不预先写定实验结论。v2 根据导师意见，提前交代物料扰动导致的工序开始延误重调度，统一摘要、引言和方法章的模块表述，并压缩第六章。

## 一、论文总体内容

### 1. 研究对象

本文研究飞机脉动装配线（Aircraft Pulsed Assembly Line, APAL）的初始排程与物料扰动导致的工序开始延误重调度。与主要决定工序加工顺序或工序—机器分配的常见车间调度不同，本文需要在同一排程过程中联合确定：

1. 下一道被调度的工序；
2. 工序所在的物理站位；
3. 满足技能和人数需求的具体工人团队；
4. 工序的开始时间与完成时间。

在初始排程开始前，各站位最终承担的任务量和技能需求尚未确定，因此本文不预先固定全部工人—站位关系。工人最初处于全局未绑定状态；某工人第一次被某站位上的工序选中后，即永久绑定到该站位。由此，各站位的人员数量和技能构成随排程逐步形成。

### 2. 核心问题

本文重点解决三个相互关联的问题：

1. 如何统一表达工序、站位、工人和技能之间的异构关系；
2. 如何避免显式枚举数量庞大的工序—站位—工人团队组合，并逐步构造合法的联合动作；
3. 如何使同一策略适应不同规模的 APAL 实例，并将主要表示与解码结构迁移到工序开始延误重调度。

### 3. 拟提出的方法

本文拟提出 HGP-PPO 框架，其策略网络暂称 HB-GAT-PN。全文统一按照三个一级模块介绍：

1. **异构图表示与全局编码**：以 Operation、Station、Worker 和 Skill 为节点，通过关系感知图注意力和全局状态池化编码多资源关系与跨站位瓶颈；
2. **可行性约束的自回归联合解码**：依次选择工序、工位和具体工人集合，并通过 task、station 和 worker 掩码以及内生绑定更新逐步维护可行域；
3. **PPO 学习与迁移**：使用 PPO 训练策略，说明跨规模兼容机制，并通过特征扩展、warm start 和继续训练适配工序开始延误重调度。

### 4. 论文准备验证的主要论点

本文拟验证：针对 APAL 的多资源联合决策，异构图表示与全局编码、可行性约束的自回归联合解码以及 PPO 学习与迁移可以形成一套统一的学习框架；同一策略在有限的中等规模实例上训练后，能够无梯度微调地处理规模差异较大的 APAL 实例，并生成满足硬约束的排程；相同的表示—解码骨架经过特征扩展和继续训练后，还可用于物料扰动下的工序开始延误重调度。

# 第一章 Introduction

## 章节功能与核心论点

本章负责说明为什么 APAL 值得研究、本文具体解决什么问题、现有方法还缺少什么，以及本文提出的机制为什么与这些困难相对应。

核心论点是：APAL 的站位负荷和技能需求由工序排序与站位分配共同形成，因此工人配置不宜完全预先固定。需要在生成排程的过程中联合决定工序、站位和具体工人团队，并同时处理异构关系、组合动作和逐步可行性；物料扰动导致工序无法按基准时刻开始后，还需要在继承已执行任务和既有资源绑定的条件下调整基准排程。

## 段落安排

**第1段：工业背景与研究对象。** 介绍大型飞机装配任务具有工序多、周期长、空间约束强和人工技能依赖明显等特点；说明 APAL 通过固定节拍推动装配对象依次经过物理站位；指出实际运行既需要生成初始基准排程，也需要在物料扰动导致工序无法按基准时刻开始后进行事件触发的调整，因此本文可归入预测—反应式调度范式。这里的“预测”指事前生成基准排程，不表示对延误事件进行预测。

**第2段：本文所研究的联合决策。** 说明每次决策需要选择工序、物理站位和具体工人团队；解释工人为什么不在排程前全部固定到站位，以及首次被选择后如何形成永久站位绑定；简要区分本文问题与 JSSP/FJSP。

**第3段：主要技术挑战。** 依次说明异构状态难以统一表示、站位人员配置与排程相互依赖、具体工人团队选择造成组合增长，以及每个子决策都会改变后续可行集合；工序开始延误重调度还需要继承冻结任务、既有工人绑定和基准排程信息。

**第4段：现有研究及其局限。** 综合三条研究线：传统装配线与 APAL 优化方法能够处理复杂约束，但通常依赖逐实例求解，并将工序调度、站位分配和人员配置分阶段处理；GNN/DRL 调度能够学习可复用策略，但动作通常集中于工序顺序或工序—机器/站位选择，较少显式构造具体工人团队；动态调度能够响应扰动，但 APAL 工序开始延误重调度还需要同时继承冻结任务、既有绑定和站位约束。由此引出本文的问题缺口与方法缺口：仍需要面向 APAL 的多资源内生联合配置，以及与之匹配的异构表示、结构化联合解码和逐步约束维护机制。

**第5段：本文方法、挑战应对与贡献。** 按照与摘要、第四章一致的顺序介绍三个一级模块：异构图表示与全局编码用于表达多类型资源关系并感知跨站位瓶颈；可行性约束的自回归联合解码用于构造工序—工位—工人团队动作，并通过逐步掩码和内生绑定维护可行域；PPO 学习与迁移用于训练策略、形成跨规模兼容结构并适配工序开始延误重调度。段末分别说明两种验证协议：使用同一锁定的初始排程 checkpoint 在不同规模实例上进行无微调评价；通过特征扩展、warm start 和继续训练检验相同表示—解码骨架向工序开始延误重调度迁移的能力。

**第6段：全文导读。** 简要说明第二章综述文献，第三章建立问题与 MDP，第四章介绍 HGP-PPO，第五章报告实验，第六章讨论结果、局限性并总结全文。

## 段落安排

**第1段：复杂装配线与 APAL 定位。** 介绍装配线平衡、复杂装配线调度和飞机装配的基本研究对象；说明 APAL 的脉动推进、物理站位、空间容量和人工技能约束；明确其与普通 JSSP/FJSP 的联系和区别。

**第2段：传统调度与优化方法。** 综述 SPT、EDD、CPM 等规则，以及 Beam Search、IG、SA、GA 等搜索或元启发式方法；说明这些方法适合作为实验基线，但通常依赖局部优先级或逐实例搜索，难以直接学习可复用的高阶联合策略。

**第3段：强化学习与图神经网络调度。** 介绍 DRL、GNN 和 GNN-PPO 在组合调度中的发展，重点讨论图表示和可变候选动作；指出相关研究主要集中于工序顺序或工序—机器选择，不能直接等同于本文的工序—站位—具体工人团队决策。

**第4段：异构资源、技能工人与团队构造。** 综述双资源、多技能工人和人员分配研究；区分工人类型/数量决策与具体工人身份选择；说明本文工序需求人数由输入给定，但团队成员需要由策略逐一选择。

**第5段：动态调度与重调度。** 介绍加工时间扰动、资源扰动、物料扰动、稳定性和重调度研究；说明本文当前聚焦物料扰动导致的工序开始延误，并要求冻结已开始工序、继承既有工人绑定，同时控制 makespan 和方案扰动。

**第6段：综合定位。** 简要说明 Ai et al. 是本课题组的前序工作；总结本文的问题缺口、方法缺口和验证贡献：排程内生的多资源联合配置、结构化联合动作解码，以及更大规模跨度上的同一策略评价。

# 第三章 Problem Formulation and MDP Modeling

## 章节功能与核心论点

本章把实际 APAL 场景转化为可计算、可复现的数学问题和事件驱动 MDP。核心论点是：初始排程需要联合确定工序站位、具体工人集合和起止时间；工人的永久站位绑定是排程过程产生的状态，而不是预先给定的固定参数。

## 段落安排

**第1段：系统对象与排程输出。** 定义正工时工序、零工时层级节点、物理站位、工人和技能集合；说明工艺前序采用有向无环图；定义完整排程需要输出的站位、团队和时间信息。

**第2段：基本假设与研究边界。** 说明工序不可抢占、团队人数由工序需求给定、每个工序只要求一种技能、工人首次使用后永久绑定站位、初始排程不考虑故障和缺勤等假设；明确本文不研究订单排序、长期班次和物料采购。

**第3段：符号表。** 集中定义工序、站位、工人、技能、前序边、标准工时、需求人数、技能矩阵、站位分配、工人分配、绑定变量、开始时间、完成时间和 makespan。

**第4段：团队加工时间与优化目标。** 给出考虑标准工时、工人效率、需求人数和协同折扣的加工时间公式；定义初始排程唯一正式目标为最小化 makespan；说明五站位 APAL 中单架飞机的线内流动时间与节拍的关系。负载标准差只作为奖励塑形，不作为第二个正式优化目标。

**第5段：初始排程约束与排程内生绑定。** 依次定义唯一站位分配、工艺前序、空间单调性、固定站位、团队人数、技能匹配、工人时间互斥、站位槽位容量和排程完整性；同时用最终绑定变量和序贯绑定状态描述工人最初未绑定、首次被某站位选择后只能继续服务于该站位，并说明该机制是排程状态转移，而不是独立的工人选站动作。

**第6段：物料扰动下的工序开始延误重调度问题。** 在初始排程模型之上定义基准排程、重调度时刻、受扰工序更新后的最早释放时刻 $r_i$ 和冻结规则；说明尚未开始的工序可以重新选择站位和团队，既有工人绑定必须继承；定义 makespan、节拍超限、开始时间偏差、站位变化和团队变化等评价项。先定义这一扩展问题，再在下一段给出初始排程与重调度共用的 MDP，避免在 MDP 之后重新打开问题定义。

**第7段：统一的事件驱动 MDP。** 定义初始排程与重调度共用的状态、联合动作 $a_t=(i_t,m_t,W_t)$ 和 task、station、worker 三层可行集合；重调度状态额外包含基准排程、冻结状态和工序最早释放时刻 $r_i$。说明环境如何计算最早开工时间，并在无可行动作时把时钟推进到最近事件；最后分别给出初始排程的 makespan 增量与负载均衡塑形奖励，以及重调度的目标增量奖励。团队大小始终等于工序给定的需求人数。

# 第四章 Proposed Method: HGP-PPO

## 章节功能与核心论点

本章说明 HGP-PPO 如何把第三章定义的 APAL 状态和联合动作转化为可训练策略。核心论点不是简单叠加 GAT、池化、Pointer 和 PPO，而是按照异构图表示与全局编码、可行性约束的自回归联合解码以及 PPO 学习与迁移三个一级模块，分别解决多资源关系表达、全局瓶颈感知、具体团队构造、逐步可行性维护和任务迁移问题。

## 段落安排

### 4.1 Overall architecture and decision flow

**第1段：总体框架。** 结合总架构图说明 APAL 状态经过异构图构造、图编码、全局池化和三阶段 Pointer 解码后形成联合动作，再由事件驱动环境更新状态并返回奖励。

**第2段：Actor、Critic 与环境分工。** 说明 Actor 产生工序—工位—工人团队策略，Critic 估计状态价值，环境负责执行动作、推进时间和校验约束；编码器分离只作为实现细节，不作为独立贡献。

### 4.2 Heterogeneous graph representation and global encoding

**第3段：节点与特征。** 介绍 Operation、Station、Worker 和 Skill 四类节点，以及工时、调度状态、负荷、技能、工人效率和绑定状态等主要特征；说明采用实例内归一化减弱绝对规模差异。

**第4段：关系与 Skill Hub。** 介绍工序前序、工序—站位归属、工序—工人执行、工人拥有技能和工序需求技能等关系；说明 Skill Hub 用于在工人和工序之间传递技能层信息。

**第5段：关系感知图编码。** 说明不同关系使用独立的 GATv2 消息变换，经过多层传播和残差连接获得工序、站位与工人的上下文表示。

**第6段：全局状态池化。** 说明按节点类型进行全局池化，把可变数量的节点压缩为固定维上下文，使策略能够感知瓶颈站位、关键工序和稀缺工人；其实际贡献由与 mean+max pooling 的消融比较验证。

### 4.3 Feasibility-constrained autoregressive joint decoder

**第7段：联合动作概率分解。** 给出策略依次选择工序、工位和 $q_i$ 名工人的概率分解；解释顺序构造可以避免显式枚举所有候选团队，但不会消除问题本身的组合复杂性。

**第8段：工序与工位选择。** Task Pointer 在当前 ready 工序中选择工序，Station Selector 在满足固定站位、空间单调性和槽位容量的站位中进行选择。

**第9段：具体工人团队构造。** Worker Pointer 根据所选工序、所选工位、候选工人和此前已选团队成员，逐一选择规定人数的具体工人；说明最终模型计划显式加入所选工位嵌入。

**第10段：逐步掩码与内生绑定。** 说明每次子选择后如何更新可行集合，排除技能不匹配、已绑定其他站位和重复选择的工人；工人首次被选中后更新永久站位绑定。

### 4.4 PPO learning and transfer

**第11段：PPO 优化。** 介绍联合动作 log-probability、GAE、裁剪策略目标、价值损失和分层熵正则；说明负载均衡只用于奖励塑形。

**第12段：跨规模兼容机制。** 说明图网络共享参数、全局池化输出固定维向量、Pointer 对当前候选逐一打分，以及实例内归一化为什么使同一模型能够处理不同节点规模；实际跨规模能力由第五章实验验证。

**第13段：向重调度迁移。** 说明重调度保留主要图表示与解码结构，同时扩展工序特征、恢复冻结任务和既有绑定，并从初始排程 checkpoint warm start 后继续训练。

### 4.5 Algorithm, complexity, and reproducibility

**第14段：算法与复杂度。** 用伪代码概括构图、编码、三阶段选择、环境转移和 PPO 更新；分别分析图编码、联合解码和环境 rollout 的计算开销，并列出主要实现参数和复现信息。

# 第五章 Experiments and Results

## 章节功能与核心论点

本章验证 HGP-PPO 是否能够生成高质量且合法的 APAL 排程，以及其跨规模能力究竟来自哪些结构。主要关注五个问题：初始排程质量、跨规模泛化、模块必要性、计算效率和重调度迁移。

由于最终模型和部分消融仍在训练，本章以下内容是正式写作计划，具体结论将在实验完成后填写。

## 段落安排

### 5.1 Experimental setup

**第1段：数据来源与实验协议。** 介绍四个由实验室提供的真实工厂 APAL 实例及其物理工序规模、五个固定物理站位、相同的站位并发槽位容量 $c_m=c$ 和工人配置；说明正式训练集以这些实例为模板，通过工序增删、工时扰动、所需技能类别变化和给定团队人数 $q_i$ 变化等方式生成，并报告生成规模、随机种子与数据清单。随后明确训练集、开发集和测试集的角色：四个原始实例不直接参与梯度训练、超参数调整、早停或 checkpoint 选择，模型与配置锁定后才在其上进行无微调评价。该协议属于原始实例级别的独立测试，但训练与测试在模板谱系上相关，因此泛化结论限定为同一 APAL 数据族内、模板相关条件下的跨规模外推。

**第2段：比较方法。** 将基线分为规则方法、搜索/元启发式方法和 APAL 适配学习方法，主要包括 SPT、CPM、Beam、IG、SA、L2D-PPO-APAL 和 Graph-DDQN-APAL。

**第3段：指标。** 初始排程以 makespan 为主要质量指标，以 complete/valid rate 为硬门槛，同时报告推理时间；重调度报告综合分及 makespan、节拍超限、开始时间偏差、站位变化和团队变化等分项。

**第4段：公平性与复现。** 说明所有方法使用相同数据、执行时间公式、工人池、约束校验器和输出格式；报告训练 seed、搜索预算、checkpoint 选择和统计方法。

### 5.2 Cross-scale initial scheduling

**第5段：跨规模主结果。** 使用同一锁定策略、无梯度微调地评价约 283、680、2338 和 3182 个物理工序的 APAL 实例；首先报告合法性，再比较各规模 makespan 和推理时间。[待填写结果]

**第6段：训练范围外表现。** 区分低于训练范围、接近训练范围和远高于训练范围的实例，分析性能是否随规模增长稳定；准确说明这些实例是 cross-scale validation 还是完全隔离的 held-out test。

**第7段：样本效率与训练规模。** 比较不同训练实例数量或不同训练规模区间，检验“少量中等规模样本即可获得跨规模能力”的主张。[待补实验]

### 5.3 Comparison with existing methods

**第8段：规则与搜索方法比较。** 比较 HGP-PPO 与 SPT、CPM、Beam、IG、SA 等方法的 makespan、合法率和求解时间；同时报告搜索预算，避免把轻量配置误写为传统算法的性能上限。

**第9段：学习方法比较。** 比较 HGP-PPO 与 L2D-PPO-APAL、Graph-DDQN-APAL，以及“只学习工序顺序”或“学习工序—工位、规则补全工人”的分层基线，检验联合动作是否确有必要。

**第10段：排程案例。** 选取一个中等规模和一个大规模实例，展示站位负荷、关键工序与工人绑定结果，解释 makespan 差异来自何处。

### 5.4 Ablation and mechanism analysis

**第11段：图关系建模与全局上下文。** 图编码采用“关系感知异构 GAT、关系合并的同构 GNN、无消息传递”三级比较，以区分异构关系建模与一般图传播的作用；全局上下文采用“注意力池化、mean+max pooling、无全局上下文”三级比较，以区分注意力加权与全局感知本身的作用。

**第12段：联合解码与工位条件化。** 比较 mask-only Worker Pointer 与显式加入所选工位嵌入的版本；比较带团队历史的自回归选择与不使用团队历史的独立工人打分；进一步比较“只学习工序”“学习工序—工位”“完整工序—工位—工人团队”三种动作深度，检验具体工人团队联合构造是否必要。

**第13段：内生绑定、Skill Hub 与掩码。** 比较公平的排程前人员预分配与排程内生绑定；在真实五类技能数据和技能瓶颈场景中比较 direct skill edges 与 Skill Hub；对逐步可行性掩码只报告无掩码时的非法动作、死锁和修复率，不把不能生成合法排程的版本作为普通质量基线。

**第14段：跨规模机制。** 在同一训练与测试协议下分别去除实例内归一化、减少属性随机化，检验跨规模表现来自共享参数、固定维池化和 Pointer 之外，是否还依赖尺度归一化与训练域随机化。

### 5.5 Efficiency and scalability

**第15段：图规模和资源开销。** 报告不同工序规模下的节点/边数、构图时间、网络编码时间、峰值显存和 CPU 内存。

**第16段：端到端效率。** 比较 HGP-PPO 在线推理与搜索方法逐实例求解的质量—时间关系，同时单独报告学习方法的离线训练成本。

### 5.6 Task-delay rescheduling

**第17段：重调度实验设置。** 介绍四个基础实例上的固定物料扰动场景，并按 low、medium、high 三种工序开始延误强度评价；所有方法使用相同基准排程、受扰工序及其释放时刻增量清单。

**第18段：重调度主结果。** 比较 HGP-PPO、规则/修复方法、搜索方法和学习基线的综合分及各原始分项，分析方法是否在不同规模和延误强度下保持稳定。[待填写最终结果]

**第19段：迁移与目标敏感性。** 比较从初始排程模型 warm start 与随机初始化训练的收敛速度、最终质量和稳定性；同时改变重调度综合目标的主要权重，报告 makespan 与稳定性分项，验证迁移效果并排除结论依赖单一人工权重的可能。

### 5.7 Robustness and chapter summary

**第20段：失败模式与结论边界。** 报告最差训练 seed、技能瓶颈、超大规模性能退化、无可行解或违反约束的情形；最后逐条回答初始质量、跨规模、模块贡献、效率和重调度五个实验问题。
