## 一、 执行摘要与核心审计结论

针对审稿人对“稳健性未知”、“微弱优势是否仅为评估噪声”的质疑，本报告对本地已完全冻结的 **21 种比较方法**、**36 个严格配对的扰动场景**，以及 **4 个工业尺度的初始排程多种子分布** 进行了全量多维统计审计。

### 核心结论速览

1. **全局非参数排名第一（Friedman 检验）**：
   在全部 19 种合法排程方法参加的全局 Friedman 检验中，统计量 $\chi_F^2 = 369.1965$（$p = 0.0000 < 10^{-15}$），表明全方法存在高度极显著差异。**本文主方法 FULL-X (BIC 120-Ep) 斩获全场第 1 名（平均秩 4.56）**，超越 L2D-PPO-APAL（4.86）、StabilityAwareRepair（5.00）及全部搜索与规则基线。
2. **对 16 个比较基线形成严格统计显著分离（Holm 校正后）**：
   在 18 项成对非参数假设检验（Wilcoxon 符号秩检验 + Holm-Bonferroni 族错误率校正）中，**FULL-X 对 16 种方法均达成 $p_{\text{Holm}} < 0.05$ 的极显著或显著优胜**（包括元启发式搜索 Beam/IG/SA、DDQN、消融模型及绝大多数启发式规则）。
3. **彻底击破对 StabilityAwareRepair（优势 3%）的稳健性质疑**：
   * **胜负比（Win/Tie/Loss）**：在 36 个场景中，FULL-X 取得 **22 胜 / 0 平 / 14 负（胜率 61.1%）**；
   * **极端稳健性（CVaR 90% 与 CV）**：FULL-X 的变异系数为 **32.74%**（StabilityAwareRepair 为 37.50%）；在最差 10% 极端场景下，FULL-X 的 CVaR 分数为 **1.4249**，显著优于 StabilityAwareRepair（**1.5739**），证明其在恶劣冲击下具有更平稳的下界保护；
   * **多目标本质揭示（分项检验）**：StabilityAwareRepair 在 680 和 2338 尺度微弱的综合分表现是以**严重牺牲完工工期和节拍超限**为代价的。在完工工期 $C_{\max}$ 上，FULL-X 形成**压倒性显著优胜（$p = 5.83 \times 10^{-6}$，32 胜 / 4 负，大效应量 $r_{rb} = -0.868$）**；在节拍超限 $\Delta_{\mathrm{ref}}$ 上，FULL-X 同样**压倒性显著优胜（$p = 2.29 \times 10^{-5}$，29 胜 / 4 负，大效应量 $r_{rb} = -0.847$）**。FULL-X 在兼顾工期和节拍的同时保持了全场最低平均开工偏差（$30.85\text{ h}$ vs $33.88\text{ h}$），展现出真正的多目标帕累托优势。
4. **彻底击破对 L2D-PPO-APAL（优势 2.2%~7.0%）的稳健性质疑**：
   * **重调度综合分**：宏观平均分优势达 **7.00%**（$0.8511$ vs $0.9152$），配对胜负为 **19 胜 / 0 平 / 17 负**；
   * **分层配对 Bootstrap 95% 置信区间**：重采样 10,000 次的分层置信区间为 **$[-0.1344, -0.0023]$**。**置信区间上限完全处于负值区间，不包含 0**！这在统计推断上给出了“FULL-X 显著优于 L2D”的确凿数学判据；
   * **物理稳定性指标压制**：FULL-X 将平均开工时间偏差从 L2D 的 $45.54\text{ h}$ 降低至 $30.85\text{ h}$（缩减 **32.3%**，21 胜 / 15 负），节拍超限量从 $42.11\text{ h}$ 降低至 $29.51\text{ h}$（缩减 **29.9%**）。
   * **初始排程超大尺度突破**：在瓶颈尺度 `real_3182` 上，FULL-X makespan 为 $1623.69\text{ h}$，较 L2D（$1804.71\text{ h}$）缩短 **$181.02\text{ h}$（改善 10.03%）**，且 100% 满足全部硬约束。
